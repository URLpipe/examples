# URLpipe in Pipedream

Call URLpipe from a Pipedream Node.js step with fetch, and use an HTTP trigger's endpoint as the webhook for async results.

The setup, step by step, is at [https://urlpipe.dev/integrations/pipedream](https://urlpipe.dev/integrations/pipedream).

- [`url_to_markdown.mjs`](url_to_markdown.mjs) — Node.js step — URL to Markdown
- [`start_audit.mjs`](start_audit.mjs) — Node.js step — start an audit, don't wait
